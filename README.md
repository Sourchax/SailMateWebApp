🛳️ **SailMate – Smart Ferry Ticketing System**  
A sleek, web-based ferry ticketing platform that streamlines the booking process for passengers  
and provides full control to operators.  
SailMate is built for modern travel—quick, secure, and beautifully designed.

---

✨ **Features**  
🎫 Book ferry tickets with real-time seat selection  
🗓️ Browse available schedules and routes  
🧑‍💼 Admin dashboard for managing ferries, routes, and passengers  
🧑‍💼 Manager dashboard for managing comments, ticket prices and statistics  
👥 Role-based authentication with Clerk  
📈 Track passenger activity and route usage  
🖥️ Responsive, mobile-friendly design  
⚙️ Backend with fully secure RESTful APIs for seamless integration
